# Презентация PADEL.SELECT для федерации — структура v9

Утверждена 2026-10-10. Заменяет прежний дек из 20 слайдов-скриншотов.

## Задача

Презентацию сначала отправляют в ФПР, читают без докладчика. Цель — чтобы федерация включила PADEL.SELECT в список обязательных сервисов для проведения турниров ФПР.

Презентация отвечает на шесть тезисов:

1. Какие боли сейчас у организаторов турниров под эгидой ФПР.
2. Какие боли у самой федерации.
3. Как сервис решает их, одну за одной.
4. Какой новый функционал получают организаторы.
5. Какой новый функционал получает ФПР.
6. Итоговая схема: после интеграции в выигрыше все.

Все показанные функции реализованы в сервисе. Тарифы не показываем. Опыт: проведены ФПР 500, ФПР 250 и несколько ФПР 100.

## Шаблон слайда «до / после»

1. Заголовок — решение в 5–8 слов.
2. Текстовый блок из двух частей: «Сейчас» (боль) и «С PADEL.SELECT» (решение), по 1–2 строки.
3. Моушен-графика на основе экрана сервиса: как сервис решает эту боль, цикл 4–6 секунд.

Шаблон получают слайды 3–9 и 11–14. Обложка, разделители, схема и финал свёрстаны отдельно. Основной формат рассылки — ссылка на веб-дек; дополнительно PDF с финальными кадрами анимаций.
