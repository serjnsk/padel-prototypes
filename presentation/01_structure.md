# Презентация PADEL.СЕЛЕКТ для федерации — структура

Черновик к обсуждению. Три части: готовый функционал по модулям → роадмап → преимущества.

## Аудитория и задача

Члены федерации: руководители, организаторы региональных турниров, судьи. Задача презентации — показать, что сервис уже проводит турниры по регламенту от заявки до итоговой таблицы, и что развивается в сторону полного покрытия регламента.

## Сценарий

| Часть | Что показываем |
|---|---|
| 1. Вступление | 1 слайд: главная страница padel.select в незалогиненном виде — на ней преимущества и концепция сервиса. Утверждён. Прототип: `prototypes/landing.html`, скриншот: `screenshots/01-landing.png` |
| 2. Готовый функционал | Кабинет организатора → создание турнира → проведение турнира → чемпионаты |

## Часть 2. Готовый функционал

| # | Блок | Что рассказываем и показываем | Объём |
|---|---|---|---|
| 2.1 | Кабинет организатора | Процесс регистрации организатора: доступ выдаёт администратор сервиса, самостоятельной регистрации нет. Коротко — разделы кабинета: Турниры, Чемпионаты / Лиги, Игроки. Экран: список турниров | небольшой |
| 2.2 | Турниры. Создание турнира | Четыре слайда = четыре шага визарда: Основные настройки, Тип турнира, Настройки матчей, Участники. Каждый шаг — прототип | 4 слайда |
| 2.3 | Турниры. Проведение турнира | Самый большой блок: каждый этап проведения турнира и все экраны на каждом этапе | самый большой |
| 2.4 | Чемпионаты | Раздел «Чемпионаты / Лиги»: список, создание, дивизионы, таблицы | средний |

Этапы проведения турнира для 2.3, по два слайда на этап (кабинет + витрина): **приём заявок — готово** → **жеребьёвка — готово** (кабинет + ТВ-табло) → **расписание и сетка — готово** (кабинет + витрина + ТВ-табло) → **завершение турнира — готово** (витрина с призёрами и результатами).

## Часть 3. Роадмап

| # | Фича | Что покажем на слайде | Прототип |
|---|---|---|---|
| 3.1 | Модуль «Судейство на вышке» | Слайд по структуре: слева логика модуля, справа экран судьи. Новый тип аккаунта «Судья», назначение на турнир и матчи организатором. Интерфейс непубличный, вся вёрстка подчинена скорости ведения счёта; тёмная и светлая темы под освещение на корте. Три варианта макета на выбор судей: А — лестница хода гейма, Б — привычный макет конкурента с колонками и центральной панелью, В — макет Б плюс лестница хода гейма. В деке вариант В | прототипы готовы, идёт опрос |
| 3.2 | Видеотабло с лайв-счётом | Табло для трансляции и для экрана рядом с кортом: счёт, пары, сет | нужен |
| 3.3 | Брендирование турнира | Цветовая схема, логотип организатора, логотипы спонсоров на страницах турнира и табло | нужен |
| 3.4 | Приложения iOS и Android | Экраны игрока: заявка, расписание, счёт, уведомления | нужен |
| 3.5 | Модуль «Медицинская помощь на корт» | Вызов медика с корта, статус, журнал | нужен |
| 3.6 | Лицензирование игроков, судей, тренеров | Контроль оплат, продлений и доступов; связь с допуском на турнир | нужен |
| — | Конструктор типа турнира | Все системы регламента: квалификация, группы, финальный этап | есть, `prototypes/tournament-type-step.html` |
| — | Раздел «Чемпионаты / Лиги» | Дивизионы, круги, таблицы | есть, `prototypes/championships-list.html`, `championship-format-step.html` |

Две последние строки — готовые прототипы; включать ли их в роадмап отдельными слайдами или показать в части 2 как «в разработке» — уточнить. Ориентиры по срокам для каждой фичи — уточнить.

## Часть 4. Преимущества

Один финальный экран с преимуществами приложения и подхода:

| # | Преимущество |
|---|---|
| 4.1 | На русском языке, полное соответствие Федеральному закону № 152-ФЗ: персональные данные хранятся на территории России |
| 4.2 | Быстрая техническая поддержка и реализация функций под конкретные задачи заказчика |
| 4.3 | Дополнительная монетизация турниров: продажа рекламных мест на экранах клубов |
| 4.4 | Уникальный удобный функционал для организаторов турниров под эгидой ФПР |

## Формат

Самодостаточный HTML-дек `presentation/index.html` в стиле главной страницы сервиса, публикуется на GitHub Pages: https://serjnsk.github.io/padel-prototypes/presentation/. Слайд — либо скриншот сервиса (когда прототипа нет), либо скриншот опубликованного прототипа https://serjnsk.github.io/padel-prototypes/ (готового или сверстанного по скриншоту сервиса); эффекты — CSS: появление слайдов, подсветка элементов интерфейса, переходы между экранами одного модуля. Экспорт в PDF для рассылки.
