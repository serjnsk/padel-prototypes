# Презентация для федерации

Самодостаточный HTML-дек в стиле сервиса (токены из `../assets/tokens.css`), при необходимости экспорт в PDF или PPTX.

| Папка | Что лежит |
|---|---|
| `screenshots/` | Скриншоты интерфейса, снятые с прототипов из `../prototypes/` |
| `roadmap/` | Прототипы и скриншоты будущих фич для слайдов роадмапа |

Дек: `index.html` (листание стрелками, пробелом, кликом, свайпом; номер слайда в адресе `#N`). Формат «до / после»: заголовок, блоки «Сейчас» и «С PADEL.SELECT», моушен-графика. Живые экраны — прототипы из `../prototypes/` во встроенных рамках, данные турнира ФПР 500 подставляет дек. Структура и статус слайдов — `01_structure.md`.

Опубликовано: https://serjnsk.github.io/padel-prototypes/presentation/
